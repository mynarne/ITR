# RC.2 검토 수정과 검증

RC.2는 로컬 검토 후보다. 배포 기준은 공개 MIT RC.1의 `main` 소스 트리다. [이전 안내 원본](history-rc1/)과 [RC.1 검증 결과](../VERIFICATION.ko.md), 기존 저장 기록은 바이트 그대로 보존했다.

| 지적 사항 | 변경 | 클라우드 결과 |
|---|---|---|
| Windows에서 브라우저 읽기와 원자 교체 충돌 | 잠긴 색인은 직전 게시를 유지한다. 저널 관찰과 색인 게시를 분리하고, 읽기 공유 위반이나 접근 오류 뒤 다음 게시를 재시도한다. 이미 본 봉인·중단은 대기열에서 보존한다. | Linux의 Windows 오류 주입과 실제 관찰 프로세스로 9/9. 각 반복의 단위 검사는 15회 연속 실패, 대기 중 새 시도 유입, 해제 후 게시 순서를 확인했다. |
| 종료 시 최종 화면 누락과 최초 게시 실패 | Ctrl+C의 최종 스냅숏과 단일 조회는 제한 시간 안에 게시를 완료한다. 제한 시간 내 게시할 수 없으면 종료 2와 진단을 반환한다. 봉인 실행 원본은 별도 폴더에 남는다. | 별도 CLI 프로세스에서 WinError 5와 종료 예외를 주입했다. 잠금 해제 뒤 봉인·관찰 종료 표시의 실제 쓰기 경로 9/9, 영구 초기 잠금의 종료 2와 임시 파일 정리 9/9. |
| 한글 진단과 증거 | 러너 및 관찰 CLI는 UTF-8로 리디렉션한다. 자식 스트림은 UTF-8 기본 또는 계획에 고정된 CP949를 사용한다. `{python}`으로 기본 UTF-8을 요청하면 격리 플래그와 함께 명시적 UTF-8 모드를 적용한다. | 한글을 정상 입력·출력한 격리 자식, UTF-8 경계, CP949 긴 실행, 잘못 지정한 코덱의 차단 총 4/4. 부모 인코딩은 테스트 자식에만 설정했다. |
| Windows 실행 환경과 긴 stdout | 작업별 임시 디렉터리, 제한된 검색 경로, 명시적 실행 파일을 사용한다. 전체 stdout에서 문구를 찾고 잘린 구간의 일치만 별도 발췌한다. 실행 정책을 승인 지문에 포함한다. | 로컬 임시 파일 생성과 사용자 환경 미상속, 원본 바이트 수와 두 파이프의 잘림, 발췌 변조 및 해시를 다시 만든 불일치의 거부를 확인했다. |
| 안내와 실제 자동화 | 독립 검토자 입력 격리, 원인·가설 메모, 권한자의 승인, ANDA 전송, 외부 앵커를 운영 절차나 설계로 명시했다. | 문서와 CLI 기능 대조. 새로운 인수 승인·리뷰 명령이나 외부 서비스 전송은 구현 범위 밖이다. |

Linux, Python 3.12에서 일반 프로젝트 회귀 10/10 그룹, 기존 합성 회귀 5/5 그룹, 동봉된 봉인 기록 7/7을 확인했다. 기존 PDF 13쪽과 같은 시도의 정규 기록을 대조했다. Node DOM 모형은 진행 화면 11개 상태와 리플레이 32개 위치를 통과했다.

별도 Windows 사본에서는 Windows 11의 Python 3.11.9 및 3.12.7에서 WinError 5와 CP949 리디렉션이 관찰됐다. 그 사본의 잠금 회복 9/9는 이번 후보의 결과에 포함하지 않는다. RC.2의 Windows 네이티브 핸들 시험은 클라우드에서 0건이며, 실제 브라우저 픽셀과 모션도 측정하지 않았다.

## 재현

검토된 RC.2 소스에서 다음을 실행한다. Windows에서는 Python마다 런처를 지정한다.

```powershell
py -3.11 -B qa/check_progress.py
py -3.11 -B qa/check_project.py
py -3.12 -B qa/check_progress.py
py -3.12 -B qa/check_project.py
```

관찰 테스트 출력에서 Windows 네이티브 잠금 실행 여부는 `windows_native_reader_lock`, 종료 경로는 `cli_shutdown_flush`와 `cli_permanent_lock_exit`로 확인한다. 네이티브 잠금 시험은 쓰기 교체를 막는 실제 읽기 핸들을 2.5초 이상 열어 둔다. CLI 종료 시험은 공유 오류와 인터럽트를 주입하고 최종 파일·종료값을 관찰한다. Linux에서는 `python3`으로 같은 두 테스트를 실행한다.

# ITR · 초안과 검증 결과

**기록 검증 시각 2026-11-20 09:48 KST** · Linux x86_64 · Python 3.12.14

ITR은 제품 목표, 선택한 스킬 규칙, 프로젝트 요구사항을 먼저 버전 고정하고, 관찰 가능한 통과 조건과 실제 증거를 검사별로 연결하는 독립 QA 스킬이다. ZIP을 풀어 `ITR/examples/preview/replay.html`을 열면 첫 회차를 재생할 수 있다. 첫 화면은 정지 상태다. 실패 카드의 상세에서 무료 배송 조건, 기대·실제값, 코드에서 확인한 원인, 다음 회귀 검사를 따라갈 수 있다.

## 합성 제품에서 무엇을 확인했나

무료 배송 기준은 10,000원 이상이다. 9,999·10,000·10,001원 주문에 기대한 배송비는 각각 3,000·0·0원이었고, 1차에서 얻은 실제값은 3,000·3,000·0원이었다. 별도 소스 인스펙션에서 비교식 `>`를 확인했다. 두 검사는 결함 지문 `receipt.shipping.threshold.inclusive` 하나를 가리킨다. 2차에는 `>=`로 고친 빌드를 사용해 두 검사가 모두 통과했다.

| 회차 / 시도 | 목적 | 통과 | 실패 | 차단 | 미실행 | 고유 결함 | 기술 판정 |
|---|---|---:|---:|---:|---:|---:|---|
| 1 / 1 | 정밀 · 첫 검사 | 7 | 2 | 1 | 1 | 1 | 실패 |
| 1 / 2 | 정밀 · 같은 빌드에서 재현 | 7 | 2 | 1 | 1 | 1 | 실패 |
| 2 / 1 | 정밀 · 수정 빌드 회귀 | 9 | 0 | 1 | 1 | 0 | 차단 |
| 2 / 2 | 정밀 · 이전 회귀 사유 정정 | 9 | 0 | 1 | 1 | 0 | 차단 |
| 3 / 1 | 변경분 · 배송 변경의 영향 범위 | 7 | 0 | 0 | 4 | 0 | 선택 범위 통과 |

실기기에서 현장 직원이 영수증을 읽는 검사는 2차에도 차단됐다. 선택적 장부 연동은 미실행이다. 3차의 미실행 4건은 전체 결과표에 남겼다. 1차 인수 시나리오에서 12,000원 장바구니 결제는 통과했고, 실제 사람의 승인 상태는 다섯 시도 모두 `not_requested`다.

## 증거와 재현

- 정규 기록은 `examples/runs/round-0001/attempt-0001/record.json`이다. 첫 시도의 SHA-256은 `51e474a90a6d5c7aa28899cbf2c4812e63ac5c08d33004c90add262e0451b742`다. 여기서 검사 11개, 최초 역할 판정 6개, 증거 9개, 순번 이벤트 31개가 연결된다. 기록상 동시 실행 카드 수는 최대 3개다.
- 5개 시도를 각각 번들 검증기와 JSON Schema Draft 2020-12 구현으로 검사했다. 모든 시도의 계획·최종 판정·이벤트·증거 파일 해시 및 선행 원본 링크가 일치했다. `tools/check_itr.py`는 동일 번호를 경쟁하는 두 프로세스 중 하나만 쓰는 동작, 오류 주입 뒤 실패 근거 보존과 새 시도 복구, 증거 및 이벤트가 달라진 복사본 거부를 검증한다.
- 첫 시도의 리플레이·Markdown·인쇄용 HTML·13쪽 A4 PDF를 생성했다. HTML 내장 JSON 전체, 보고서의 KST 시각과 단계별 네 상태, 고유 결함 수, 증거 해시 9개를 원본에 대조했다. PDF는 PyMuPDF로 조판했으며 페이지별 렌더와 한글 표기를 확인했다. CLI 결과와 산출물 해시는 `qa/package-checks.json`에 있다.
- `node qa/check_replay.cjs examples/preview/replay.html`로 실제 내장 JavaScript를 오프라인 DOM 모형에서 실행했다. 32개 재생 위치, 카드 11개, 의존선 12개, 동시 활성 최대 3개, 자동 스크롤 0회를 확인했다. 결함 통합 전의 표시 제한과 수동 현재 작업 이동, 모션 감소 설정, 타이머와 마지막 시점의 실패 상세도 검사했다. 인쇄용 HTML과 PDF 본문은 푸터·공백·활자 합자를 정규화한 후 8,846자가 모두 일치했다.

## 수행 범위

| 실행으로 확인 | 설계 또는 미확인 |
|---|---|
| 합성 영수증 CLI의 실제 단위·통합·시스템·인수 시나리오와 소스/설정 인스펙션 | 임의 제품에 맞춘 어댑터, 다른 OS·시뮬레이터·실기기에서의 제품 검사 |
| 로컬 결정 함수의 역할별 입력·최초 결과 봉인, 근거를 통한 결함 통합 | 별도 AI 서비스 6개의 독립 컨텍스트, 실제 이해관계자의 인수 승인 |
| 저장된 이벤트 리플레이 로직, 자체완결 HTML·MD·실제 PDF 생성과 대조 | 실시간 이벤트 구독, ANDA의 Notion·Discord 전달 |
| PDF 전 페이지 시각 검사와 리플레이 DOM 동작 검사 | 브라우저 픽셀·모바일 레이아웃·실제 애니메이션 육안 확인. 클라우드 브라우저의 로컬 파일 접근과 헤드리스 Chromium의 소켓 생성이 실행 환경에서 차단됨 |
